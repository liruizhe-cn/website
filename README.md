# Personal Website

A quiet personal website for selected interests, projects, résumé information,
and contact links.

## Built With

- Astro
- TypeScript
- CSS
- Astro Icon

## Development

```bash
npm install
npm run dev
```

The local site is available at `http://localhost:4321`.

## Build

```bash
npm run build
npm run preview
```
